🔐 隱私權政策

YT萃取器 Chrome 擴充功能  ·  最後更新：2026-11-12

一句話摘要：本擴充功能將 YouTube 影片內容（URL、字幕、音訊）、Podcast 音檔、或你選取的文字，傳送至 Google Gemini API 進行 AI 分析，分析結果與設定資料儲存在你的裝置本機。我們沒有自己的後端伺服器，不收集任何資料。

1. 傳送至 Gemini API 的資料

當你點擊「分析」時，本擴充功能會依下列分析模式擇一將資料傳送至 Google Gemini API（由你提供的 API 金鑰驗證）：

  • 🔓 yt-dlp 字幕橋接（每次分析都會嘗試，需電腦上先跑過一次 setup_caption_bridge_helper.py 設定精靈才會真正生效）
    擴充功能會跟 YouTube 官方字幕擷取「平行賽跑」，同時透過 Chrome Native Messaging（nativeMessaging 權限，安裝擴充功能時即授權，不需另外操作）呼叫本機安裝的 yt-dlp 抓取字幕，兩邊誰先成功就用誰，藉此繞過 YouTube 官方字幕 API 偶發的反爬蟲封鎖。此流程僅在你自己的電腦本機執行，只有影片 ID 會傳給本機的 yt-dlp 程式，不涉及任何第三方伺服器或資料上傳；抓到的字幕文字接著才會依下方一般流程傳送至 Gemini API 分析。未跑過設定精靈的使用者，這個步驟會自動快速失敗、無痛退回原本的字幕擷取方式，不影響其他任何功能。
  • ⚡ URL 直傳模式（預設，適用已建索引的 YouTube 影片）
    影片的 YouTube URL 會直接傳送給 Gemini，由 Google 自行讀取影片內容。 你的裝置不下載影片；傳送的僅為 URL 字串。
  • 💬 字幕模式（URL 直傳失敗時備援）
    字幕文字（從 YouTube 伺服器下載）會傳送至 Gemini API。
  • 🎧 AI 聽打模式（字幕讀不到時的第一備援，2026-11 新增）
    只傳送 YouTube 影片的 URL 字串與要聽的時間範圍（起訖秒數與取樣率）給 Gemini，由 Google 讀取影片音訊並轉成逐字稿。你的裝置不下載影片；轉出的逐字稿只暫存在目前這個分頁的記憶體（重新整理或關閉頁面即消失），我方不收集、不上傳到我方伺服器。
  • 🎬 視覺分析模式（無字幕備援）
    與 URL 直傳模式相同，僅傳送 YouTube URL 字串，由 Gemini 自行讀取影片畫面內容，用於字幕/URL直傳皆失敗時的備援分析。
  • 💬 留言模式（長影片 / 無字幕最終備援）
    影片的熱門留言文字（透過 YouTube InnerTube API 取得）傳送至 Gemini API。
  • 💬 留言解讀（選用，需登入，2026-07-20新增）
    不論影片有無字幕都可手動觸發：分析熱門留言的觀眾反應與熱議話題，作為內容摘要之外的額外分析。資料來源與傳送方式同上方「留言模式」。
  • ⛏️ 淘金模式（需登入，僅支援有字幕的影片）
    使用與「字幕模式」相同的字幕文字，額外分三次呼叫 Gemini API 做結構化萃取與驗證篩選，不傳送任何新增的個人資料。
  • 🔍 選字問AI（需登入）
    你在摘要/淘金結果中選取的文字（僅限選取範圍內的文字本身，不含上下文）會傳送至 Gemini API，並啟用 Google Search grounding（Google即時搜尋）以提供最新解釋。
  • 🎙️ Podcast 訂閱摘要（需登入 + 你額外授權的網域存取權限）
    訂閱的 Podcast 節目新集數音檔會從其託管網域（例如 SoundOn、Firstory 等，因各節目託管平台不同，需要 optional_host_permissions 動態授權）下載，並透過 Google Gemini Files API 上傳音檔本身進行摘要，摘要完成後由 Google 端刪除暫存音檔（依 Gemini Files API 規則，上傳檔案預設 48 小時後自動刪除）。
  • 🌙 今日回顧（手動觸發，免費方案每月3次，Pro無限次；Pro可額外設定每日自動於指定時間產生並跳出系統通知，需累積當日3支以上分析紀錄才會觸發，內容不足時不會發送）
    將你當天已產生的摘要文字（非原始逐字稿，是已經AI處理過的摘要內容，最多1500字/篇）彙整後傳送至 Gemini API，整合成單一回顧報告。回顧結果會與其他分析紀錄一併儲存在本機。
  • ⏳ 等待時的標題預讀（分析拖過約 8 秒仍未完成時自動執行）
    為了讓你等待時有東西可讀，本擴充功能會把 YouTube 頁面上公開可見的影片標題、頻道名稱、影片長度（不含字幕、留言或任何新增個人資料）傳送至 Gemini API 一次，並可能啟用 Google Search grounding（Google即時搜尋）查證，產出一小段標明「非影片內容」的背景導讀，顯示在面板。搜尋額度不足時會改用只依標題推測的版本（不啟用搜尋，必要時依序嘗試備援模型）。正式摘要完成後此導讀即被取代；導讀不寫入分析歷史，也不計入每日使用次數。
  • 📍 地點抽取（主摘要完成後自動執行）
    產生主摘要後，本擴充功能會把同一份已取得的影片文字（字幕或留言，不含任何新增個人資料）額外傳送至 Gemini API 一次，抽取影片中明確提及的真實地點（城市、景點、店家等），在面板顯示成可點擊的地點列表。點擊地點會在新分頁開啟 Google 地圖搜尋，該地點名稱會成為 Google 地圖網址的一部分（等同你自己在 Google 地圖輸入該地名搜尋）。僅在影片有原始文字（字幕/留言模式）時執行，URL 直傳與視覺分析模式不會觸發。

以上所有資料僅用於產生摘要，遵循 Google AI 使用條款 與 Google 隱私權政策。

2. 頻道 / Podcast 訂閱自動摘要（背景處理）

訂閱 YouTube 頻道或 Podcast 節目後，本擴充功能會用 Chrome alarms API 定期（背景）檢查是否有新影片/新集數，偵測到新內容時自動（不需要你手動點擊）依上方「傳送至 Gemini API 的資料」相同的資料流程產生摘要卡片，並透過 notifications API 顯示系統通知。

  • 此背景流程只在你主動訂閱的頻道/節目上執行，不會掃描或存取你未訂閱的內容
  • 產生的摘要卡片儲存在本機（chrome.storage.local），可在 popup 內查看或移除
  • 訂閱 Podcast 節目時，因各節目音檔託管網域不同，會請求 optional_host_permissions（動態網域存取權限）——這個授權彈窗只在你輸入 Podcast 連結時才會出現，YouTube 頻道訂閱不需要此授權

3. 知識庫（File Search，選用功能）

啟用知識庫功能後，你的分析摘要卡片（影片/節目標題＋AI 產生的摘要內容，非原始影片或逐字稿）會透過 Google Gemini File Search API 上傳至以你自己的 API 金鑰建立的知識庫儲存區，用於之後的跨影片問答檢索。

  • 與其他分析功能的關鍵差異：這是持久化儲存——上傳的文件會一直保存在 Google 伺服器上（隸屬你自己的 Google AI 帳號），不會像 Podcast 音檔那樣 48 小時後自動刪除
  • 上傳範圍僅限摘要卡片文字，不含你的登入資料、API 金鑰或瀏覽紀錄
  • 在知識庫頁面點「重建」會先刪除舊文件再重新上傳；刪除卡片時會一併刪除對應的雲端文件
  • 解除安裝本擴充功能不會自動刪除已上傳的雲端文件——移除前請先在知識庫頁面清空，或之後以同一把 API 金鑰透過 Google AI 介面自行刪除
  • 此儲存區綁定你自己的 API 金鑰與 Google 帳號，我方無法存取其內容

4. Pro 授權驗證（Gumroad）

升級 Pro 後，你輸入的授權碼會傳送至 Gumroad（第三方數位商品金流平台）的授權驗證 API，確認購買是否有效。

  • 傳送的資料僅為授權碼本身，不含你的個人資料
  • 驗證成功後，授權狀態（是否為Pro）與授權碼會儲存在你的裝置本機，用於後續每 7 天自動背景重新驗證一次（確認訂閱仍然有效、未退款/未取消）
  • 金流本身（信用卡資訊等）由 Gumroad 直接處理，我方完全不經手、不儲存任何金流資料

此流程遵循 Gumroad 隱私權政策。

5. 儲存於你裝置本機的資料

以下資料透過 chrome.storage.local 儲存在你的電腦上，不會傳送至任何第三方（除 Gemini API 分析本身外）：

  • Gemini API 金鑰 — 你自行輸入並儲存，僅用於呼叫 Gemini API
  • 分析歷史紀錄 — 最近 50 筆摘要（每筆最多 1,500 字），含影片標題與影片 ID
  • 每日使用次數 — 免費方案的每日次數計數
  • 登入資料（選用，Google 帳號登入後）— 電子郵件、顯示名稱、大頭貼網址、帳號識別碼（sub）
  • 訂閱清單與摘要卡片（選用，訂閱頻道/Podcast後）— 訂閱的頻道ID/Podcast RSS網址、標題、縮圖網址，以及自動產生的摘要卡片內容
  • Pro授權碼與授權狀態（選用，升級Pro後）— 見上方「Pro授權驗證」章節
  • 收藏庫（選用，你主動點擊收藏後）— 最多200筆，獨立於50筆上限的分析歷史紀錄之外儲存，不會被自動清除
  • 功能使用次數 — 「分流」「Anki 匯出」「來源包匯出」「複製 Markdown」「心智圖大綱」「我做了／還沒」這幾個功能各被點了幾次，以及第一次與最近一次點擊的時間。只有次數與時間，不含影片、標題或任何內容，也不會傳送出去；你可在擴充功能視窗的「看完之後・使用次數」看到這些數字
  • 錯誤紀錄 — 最近 30 筆程式錯誤，每筆只有時間、發生位置與錯誤訊息（例如「Google AI 回應太慢」）。寫入前會先把 API 金鑰樣式與過長的引用文字遮掉，不記錄影片內容、AI 回傳原文或影片 ID。這份紀錄只存在你的電腦，不會自動傳送；只有你自己在擴充功能視窗按「🐛複製診斷資訊」並把內容寄給我們時才會離開你的電腦，寄出前你可以先看過內容。5.44 以前的版本曾把 AI 回傳原文的前 800 字與影片 ID 寫進這份紀錄；更新到 5.45 後不再寫入，複製診斷資訊時也會濾掉舊紀錄裡的這些欄位，但已存在你電腦上的舊紀錄不會自動刪除（移除擴充功能即可清除）

OAuth 存取 Token 僅存於記憶體（不寫入磁碟），瀏覽器關閉後即消失。

6. Google 帳號登入（選用）

你可選擇以 Google 帳號登入以解鎖進階功能。登入流程透過 Google OAuth 2.0 進行。我們會取得以下資料：

  • 電子郵件地址（email）— 識別帳號
  • 顯示名稱（name）— 顯示於面板
  • 大頭貼網址（picture）— 顯示用途
  • Google 帳號識別碼（sub）— 識別唯一用戶

以上資料僅儲存在你的裝置本機，不上傳至任何伺服器。

登出時，本擴充功能會撤銷 Google 端的存取授權，並清除所有本機登入資料。

7. 我們沒有後端伺服器

本擴充功能不設有任何自建後端伺服器。所有 API 呼叫皆由你的瀏覽器直接發出至第三方服務本身（Gemini API 使用你自己的金鑰；Gumroad 僅在升級Pro時發出授權驗證請求），資料不經過我方任何中間服務。

8. 權限說明

  • activeTab / scripting — 在 YouTube 頁面注入面板 UI
  • storage / unlimitedStorage — 儲存 API 金鑰、設定、摘要歷史、訂閱清單至本機（訂閱功能累積的摘要卡片可能超過預設 5MB 限制，故需要 unlimitedStorage）
  • identity — Google OAuth 登入流程
  • alarms — 頻道/Podcast訂閱的定期背景檢查排程、Pro授權每7天自動重新驗證排程
  • notifications — 訂閱的頻道/節目有新內容摘要完成時顯示系統通知
  • host_permissions（api.gumroad.com） — Pro授權碼驗證專用，僅在你輸入授權碼時才會發出請求
  • nativeMessaging — 呼叫本機 yt-dlp 字幕橋接程式專用（見上方「yt-dlp 字幕橋接」說明），安裝擴充功能時即一併授權；此權限本身不會讓擴充功能存取任意本機程式，只能連線到你透過 setup_caption_bridge_helper.py 明確註冊過的單一橋接程式，沒跑過設定精靈就不會有任何本機程式被實際呼叫
  • optional_host_permissions（https://*/*，動態請求） — 僅在你訂閱 Podcast 節目時才會跳出授權請求。因 Podcast 音檔可能託管在任意網域（SoundOn、Firstory、Anchor 等平台各不相同），無法預先列舉所有可能網域，故採用動態授權；YouTube 頻道訂閱與其他所有功能都不需要此權限

9. 資料分享

我們不會將你的個人資料出售、出租或分享給任何第三方，除非：

  • 法律要求（例如法院命令）
  • 你明確同意

10. 資料刪除

若要完全清除所有本機資料，請在 Chrome 擴充功能管理頁面移除本擴充功能。 登出可清除登入相關資料，但不影響 API 金鑰與摘要歷史。取消訂閱頻道/Podcast會移除對應的訂閱清單與摘要卡片。

11. 兒童隱私

本服務不針對 13 歲以下兒童。若發現意外收集了兒童資料，請聯絡我們。
